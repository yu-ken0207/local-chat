# 多 AI 討論（設計）

狀態：第一版做完（2026-10-30）：M1–M6、M7a（頭像生產線、換頭像）、M8a（真模型測試）都 commit 了，測試 537。M7b 788 張像素頭像（C 風格）也做完了。還沒做：M8b iPhone 驗收。決定都在第 2 節；還沒定的在第 13 節。

## 1. 目標

一次跟好幾個 AI 聊，AI 之間會自己討論，不是每句都轉頭問你；你只是其中一員。

使用者提的 7 點：

1. 一般對話就有，不只討論串；要顧到每個 AI 的記憶（上下文）放不放得下。
2. 設定裡管理 Agent；你想像一個 Agent，AI 幫你補完整。
3. 誰加入：可以自己選，也可以讓 AI 自己加入。
4. 頭像：用測試主機生像素風頭像。
5. 最後有投票、結論。
6. 每個 AI 自己決定何時講、回誰；設定裡可改；也要能全部交給 AI。
7. 不是只圍著你的題目轉，AI 之間要自己討論。

## 2. 決定（2026-10-30）

| 項目 | 決定 |
|---|---|
| 放哪裡 | 一般對話就有。每段對話多一個「成員」名單，預設只有 1 個 AI（跟現在一樣），加人就變多人討論。討論串沿用原對話的成員，也能另外加人 |
| 發言方式 | 預設**自由搶話**（AI 舉手打分）。設定裡另有：主持人點名、輪流、只回被 @ 的 |
| 模型 | 預設跟著對話目前的模型；個別 Agent 可以指定別台電腦或別的模型 |
| 搶話機制 | 每則說完，每個 AI 回一行「想不想講（0–10）、想回誰」，分數最高的講 |
| 何時停 | 沒人想講就停；你每說一句，AI 最多連續講 12 則（設定裡可改） |
| 誰加入 | 兩種都有，群組設定裡選：預設自己選（加「幫我挑」）；打開「讓 AI 自己加入」後，「我的 Agent」裡勾了「可以自己加入」的也會舉手 |
| 你說話 | 一定有人回，誰回由他們搶 |
| 建 Agent | 一句話生成完整角色卡，可逐欄改，不滿意「再生一個」 |
| 頭像 | 測試主機生像素風頭像，**每個角色一張**（內建 788 張）；自己建的從裡面挑或用相簿 |
| 收尾 | AI 覺得差不多會提議「要收尾嗎？」，你決定；全自動時 AI 自己收。收尾＝列方案、每人投票加理由、結論卡 |
| 畫面 | **只有多個 AI 的對話**改成聊天氣泡（像 LINE）；一對一維持現在的終端風 |
| 回覆長度 | 短，像聊天（1–4 句）；長按某則可以「請他展開講」 |
| 內建 Agent | 兩個 MIT 專案的 **788 個全部放進去，保留原文**（見第 8 節） |
| 名冊 | 「圖鑑」（788 個，分類＋搜尋）＋「我的 Agent」（加進來的、自己建的） |
| 跨對話記憶 | 要。每個 Agent 有自己的筆記，收尾後寫，下次討論帶著 |
| 範圍 | 一次全做（第 12 節的 M1–M8），中間每步測過就 commit |
| 公開 | 暫時不公開，所以越獄、髒話角色照原樣放；資料裡標記，公開前再檢查 |

## 3. 名詞

- **Agent**：一個有名字、頭像、角色設定的 AI。
- **圖鑑**：App 內建的 788 個 Agent，唯讀。
- **我的 Agent**：從圖鑑加進來（複製一份，可以改）或自己建的。
- **成員**：某段對話裡有哪些 Agent。
- **舉手**：每則說完，問每個 AI 想不想講的小呼叫，不寫內容。
- **整理者**：系統角色，負責摘要、列方案、寫結論卡，不算成員、不佔名額。

## 4. 發言流程

```
有人說完一則（你或某個 AI）
  停下條件？（暫停中／連續已講 12 則／沒人想講）── 是：停，等你
  否：所有成員同時舉手（只帶名字＋一句話介紹＋最近幾則）
    分數加權：積極度、被 @（一定講）、剛講過的扣分（避免同一人連講）
    最高分 >= 門檻：他正式發言（帶完整角色原文），回他想回的人
    你剛說完：就算大家都低於門檻，最高分的也要回
```

- 舉手用 Ollama 的 `format`（JSON 格式）回 `{score, reply_to, ready_to_conclude}`。
- 同一台主機有開並行（測試主機是 4）時，舉手可以同時問；沒開就排隊，還是能用，只是慢。
- 主持人點名：整理者看最近幾則，選下一個人和回誰（每輪一次呼叫）。
- 輪流：照成員順序。
- 只回被 @ 的：沒被 @ 就不講。你沒 @ 人時，最近講話的那個回。
- 讓 AI 自己加入：「我的 Agent」裡勾了「可以自己加入」的人也一起舉手，門檻比成員高（例如 7 分）。贏了就加入，畫面出現「某某加入了討論」。
- 全自動：不等你，聊到沒人想講或到上限就自己收尾。
- 背景執行沿用現在的 runs：換對話、關討論串都會繼續；暫停鈕可以隨時停。

## 5. 每個 AI 看到什麼（記憶）

正式發言時，送給模型的是：

1. **系統訊息**：群組規則（你是誰、成員有誰和各自一句話介紹、回覆 1–4 句、用名字稱呼人、可以 @ 人、回答語言）＋**這個 Agent 的角色原文**＋**他的筆記**（最近幾則，有上限）。
2. **前情摘要**：對話太長時，前面的內容由整理者摘要成一段（大家共用一份）。
3. **最近幾則**：自己說的當 assistant，別人說的當 user，前面加上「【名字】」。

**上下文預算**：用 `contextFor()` 查主機實際的上下文上限，留空間給回答，從最新的往回塞，塞不下的進摘要。

**原文放不下時**：agency 的原文平均約 3,700 tokens，主機上下文只有 4K 時會塞不下。這時自動截短（保留開頭的身分與重點段落），並在那則訊息下面註明「角色說明太長，已截短」。

**筆記**：收尾後每個 Agent 用幾行寫下這次的立場和學到的事（參考 Generative Agents 的記憶）。存在 Agent 身上，下次任何討論都會帶著。設定裡可以看、改、清除。

## 6. 收尾（投票、結論）

1. **提議**：舉手時多數人回 `ready_to_conclude`，畫面出現「要收尾嗎？」。你也可以隨時按「收尾」。全自動時直接收。
2. **列方案**：整理者從討論中列出 2–4 個方案（沒有明顯方案時，改成「同意／不同意」某個結論）。
3. **投票**：每個 Agent 同時投一票，加一句理由。你也可以投。
4. **結論卡**：寫出共識、分歧、待辦，加上票數。結論卡可以釘在對話最上面。
5. **筆記**：每個 Agent 寫自己的筆記（第 5 節）。

## 7. 角色卡

自己建的 Agent，AI 會從一句話生成以下欄位：

| 欄位 | 說明 |
|---|---|
| 名字 | 顯示用 |
| 一句話介紹 | 舉手、成員名單、圖鑑都用這句 |
| 專長 | |
| 立場與個性 | |
| 說話風格 | |
| 盲點 | 讓討論有張力，也讓別人知道要補哪裡 |
| 積極度 | 0–1，影響舉手分數 |
| 頭像 | 從 788 張像素頭像挑最接近的；可換、可用相簿 |
| 模型 | 預設跟著對話；可指定別台電腦或別的模型 |
| 可以自己加入 | 開了，「讓 AI 自己加入」的對話裡他會舉手 |

圖鑑的 Agent 保留原文當角色設定，另外存名字、一句話介紹、分類、emoji、作者、來源。加到「我的 Agent」時複製一份，之後可以改。

## 9. 頭像

- 測試主機的 ComfyUI（Z-Image Turbo）先生 3 種像素風樣本，你挑一種。
- 每個角色依名字和介紹各生一張，788 張，約 40 分鐘。
- 縮成 48×48 的像素格、減成 32 色，再放大兩倍成 96×96（32pt 的頭像在 3 倍螢幕剛好不模糊），一張約 3 KB。
- 每個角色一個小檔（`assets/agents/avatars/N.png`，對照表 `src/agents/avatars.ts`），畫面用到才載入。原本想拼成一張大圖，但 788 張拼起來手機解開要好幾十 MB，而且整張一定會被載入，所以改掉（2026-10-30）。
- 外觀描述：`scripts/build_avatars.py describe` 請測試主機的 gemma4:31b 依名字和介紹各寫一句英文描述（男女老少、職業特徵、奇幻角色照角色畫），存 `scripts/catalog/avatar-subjects.json`。
- 自己建的 Agent：一句話生成時自動用圖鑑裡名字或專長最接近的角色頭像；編輯頁可以「換頭像」從 788 張挑或改回 emoji。相簿照片還沒做。
- 你本人在氣泡右邊，不用頭像。

## 10. 畫面

- **多個 AI 的對話**：聊天氣泡。你在右邊；AI 在左邊，帶頭像和名字。回某人時上面一行小字「回覆 某某：…」，點了跳到那則。「某某加入了討論」用置中小字。
- **進行中**：舉手時顯示「大家在想…」，有人講時顯示「某某正在輸入…」。
- **標題列**：成員頭像疊在一起，點開成員面板，可以加人、拿掉人、按「幫我挑」，也有群組設定：發言方式、讓 AI 自己加入、連續上限、全自動。
- **輸入框**：打 @ 跳出成員清單，另有暫停／繼續鍵和「收尾」鍵。
- **結論卡**：釘在對話最上面，點開看完整內容。
- **設定的「Agent」頁**：
  - 兩個分頁：「我的 Agent」、「圖鑑」（分類加搜尋）。
  - 建立新的：寫一句話，AI 生成角色卡。
  - 編輯角色卡、看或清除筆記、選頭像。
- **長按 AI 訊息**：多一個「請他展開講」，他會不限長度回答那一則。

## 11. 資料庫（v7）

- `agents`：我的 Agent。欄位：id、來源（lobe／agency／自己建）、來源 id、名字、介紹、角色原文或角色卡欄位、積極度、頭像（sprite 編號或相簿照片）、主機與模型（可空）、可以自己加入、建立時間。
- `session_members`：哪段對話有哪些 Agent，記下怎麼加入的（你加的、AI 自己加入、被 @ 拉進來）。
- `sessions` 加群組設定：發言方式、讓 AI 自己加入、連續上限、全自動、前情摘要、釘選的結論卡。
- `messages` 加 `agent_id`（哪個 Agent 說的）、`reply_to`（回哪一則）；結論卡、投票、「加入了討論」用 `detail` 區分。
- `agent_notes`：Agent 的筆記，記下來自哪段對話。
- 備份與還原要一起帶這些表。

## 16. 找 Agent 一起討論、討論串的成員（2026-10-31 使用者決定）

一般聊天問到一半想找人討論，不用先選好成員：

- **討論串有自己的成員**，跟原對話分開：一般聊天開的討論串，點標題選「成員與討論設定」邀請 Agent，原對話照樣是一般聊天。從多人討論開的討論串照舊沿用原對話的成員。
- **一般聊天打 @「我的 Agent」**：把他拉進來，變成多人討論，由他回你這句。@ 名單在一般聊天只列「我的 Agent」（圖鑑 788 個太多，要從圖鑑找人用下面的「找 Agent」）。
- **說「找懂 xx 的 Agent 一起討論」**：AI 叫工具 `invite_agents`（App 內建，不需要 MCP：圖鑑和挑人都在手機上），App 照話題找 2–4 位，出一張**勾選卡**：
  - 「我的 Agent」有適合的優先，不夠再從圖鑑找（「幫我挑」也一樣）
  - 預設全勾，每位附一句「為什麼找他」，可以「換一批」（看過的不再挑）
  - 「加入並開始」：勾的人加進來，**原本的 AI 退場**，Agent 接著回你那句話
  - 「不用了」：AI 照一般聊天自己回答（不會說「沒有做」）
  - 找不到合適的人：不出卡片，AI 自己回答
- 「找 Agent」一直開著（不碰個人資料，設定裡沒有開關）。模型不會叫工具時，系統提示詞請它告訴使用者：點標題、「成員與討論設定」、「幫我挑」。
- 已經是多人討論時不用這個工具：討論中加人照舊用 @ 或「幫我挑」。

真模型實測（測試主機 gemma4:31b）：說「幫我找幾個懂這方面的 Agent 一起討論」會叫工具，找人約 10 秒，你的「財務長」排第一、圖鑑補「後端架構師」，各附一句為什麼；加入後約 15 秒講完一輪。

## 17. 點頭像看 Agent 的資料（2026-10-31 使用者決定）

像 Teams 的聯絡人卡：點氣泡旁 Agent 的頭像，資料卡從那個頭像長出來、蓋在對話上（後面變暗）；點外面、往下拉或兩指畫 Z 縮回頭像。

- 內容：頭像、名字、一句介紹、「這段說了 n 次，積極度：愛講」；自己建的寫專長、立場、風格，圖鑑來的寫分類、個性；最近 3 則筆記（沒有就不顯示）
- 按鈕：@他（填進輸入框）、編輯（圖鑑來的先收進「我的 Agent」再打開編輯）、移除（離開這段討論，說過的話留著，可以復原；已經離開的人沒有這顆）
- 按鈕都等卡片縮回去才動作（兩層面板不同時動）
